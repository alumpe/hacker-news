# HN Reader

A quiet, read-only Hacker News client for scanning Top Stories and reading discussions.

- Two independently scrolling columns keep stories and comments side by side.
- Infinite scrolling loads more stories as you approach the end of the list.
- Comment trees load progressively and can be collapsed by branch.
- Atkinson Hyperlegible Next and the system color scheme keep reading comfortable.
- Built with SvelteKit 3 remote functions and async components, the official Hacker News API, and Cloudflare Workers.

## Development

```sh
bun install
bun run dev
```
